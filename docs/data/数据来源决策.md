# 数据来源决策

> 整理：2026-09-07。以下是仓库已有的 2026-08-23、2026-08-24 与 2026-08-27 调研和验收结论，没有重新联网核验。来源状态改变后应重新实测；强制发布规则见[数据获取与发布规则](数据获取与发布规则.md)。

| 来源或方式 | 已有证据与限制 | 项目决定 |
|---|---|---|
| 厂商专用适配器 | 通用浏览器/HTTP 获取不稳定；后续 AMD 适配已覆盖 13 个固定 CPU，65 条字段证据进入 release v2；两次 Task Scheduler 验收命中 13 个 304 | 按厂商品类实现确定性适配，不能将单一成功外推为所有厂商可用 |
| pc-part-dataset | 锁定 commit `c52a04ca9465c83997ed335f7767b09a2005dd26`，技术可读取但数据陈旧 | 保留候选基线；美元价格丢弃，不能作为人民币报价 |
| dbgpu 2025.12 | 可提供 GPU 芯片/参考板字段 | 仅作相应层级兜底，不能冒充具体非公版板卡参数 |
| BuildCores OpenDB | 当时取到 33,876 个 JSON，四个样本有精确或近精确匹配 | 作为扩容候选；版本锁、ODC-By 署名与质量核验完成后再使用，不直接晋级核心池 |
| 浏览器和搜索摘要 | 京东商品页跳转登录；摘要缺少商家、变体、库存和优惠条件 | 只用于发现链接或人工复核，不生成正式价格 observation |
| 京东联盟 API | 网关可达但需要应用、签名和权限 | 该路线已放弃，不属于当前计划 |
| 模型辅助抽取 | AMD/Lian Li 样本可提取，技嘉样本曾发生字段语义误映射 | 仅人工显式触发，进入候选/隔离区，不能自动发布或补造事实 |
| SerpApi/Baidu Shopping | 2026-08-27 固定 12 SKU：购物结果 0，双商家匹配 0，接受 observation 0 | `serpapi_baidu` 与映射保持禁用/待 canary，不能激活每日价格任务 |
| SerpApi 其他引擎 | 同日 Bing `zh-CN` 返回零购物结果；当时 Google Shopping 支持地区不含大陆，未继续测试 | 不拿普通摘要或外币结果替代大陆人民币结构化报价 |
| 人工价格 CSV | observation、review/publish 与 last-known-good 路径已实现 | 当前可用的价格维护路径，按[价格任务](../ops/价格任务.md)操作 |

## 自动价格来源的失败证据

真实 run：`141190fa-925c-59c2-9beb-8fd228127fe4`。12 个 SKU 中至少 10 个应有购物结果、至少 9 个应有双商家精确匹配；实际均为 0。补充购买意图和消费品对照仍无购物结果，不能仅靠改查询词视为修复。

当时账户接口可用，Free 套餐与项目每月 240 次限制生效；结束用量为 16/250。该数据只说明当次环境，不代表当前额度。未发布价格、未将 160 个现有核心件切为 96/64、未安装每日任务。

恢复自动来源时重新验证结构化 CNY、精确变体、商家、HTTPS 商品链接、双商家选价、零误匹配和两个真实轮转周期。相关未完成工作统一见[路线图](../product/路线图.md)。
