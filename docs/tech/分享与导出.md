# 分享与导出

> 分享只暴露已保存的不可变 build 版本，不共享会话；本文维护读模型、导出和公开访问边界。

## 1. 目标与边界

分享与导出 让配置单可以离开工作台被查看和保存,同时守住三个边界:

- 分享内容保留价格快照日期、校验三态和三条免责。
- 分享链接不泄露匿名身份、session、聊天、run 和 Agent 内部数据。
- CLI、所有者 API 和公开 API 复用同一确定性 presenter,不在 Next.js 复制业务规则。

本阶段支持 Markdown 下载、可撤销只读链接和 1200×630 PNG 分享图。不支持协作编辑、评论、短链接、访问统计、正式公网发布或新 Agent 能力。分享与导出 的实现与测试不调用大模型。

## 2. 共享 presenter

产品 API 已将 builds JSONB 解码、金额、版本树、diff 和 Markdown 渲染抽到 `internal/presenter`。分享与导出 直接复用该包:

1. `cmd/builds` 保持原 CLI 参数与文本格式。
2. 所有者导出与公开导出使用同一 Markdown 渲染器。
3. 公开 JSON 先经过独立的最小披露映射,不直接序列化 `BuildView` 或 store row。

前端不重算总价、预算差或兼容性,不自行拼接免责文案。金额继续使用两位小数字符串。

## 3. 分享存储与 token

`00006_p9_shares.sql` 在 产品 API 预建表上增加管理标识和跨重启幂等约束:

| 列 | 类型 | 说明 |
|---|---|---|
| id | bigint identity | 内部主键,不出 API |
| public_id | uuid | 只向所有者暴露的撤销标识 |
| build_id | bigint | FK builds(id),分享固定到不可变版本 |
| client_request_id | uuid | 创建请求的幂等键 |
| token_hash | bytea | 原始 token 的 SHA-256,唯一 |
| created_at | timestamptz | 创建时间 |
| revoked_at | timestamptz nullable | 软撤销时间 |

`SHARE_TOKEN_SECRET` 必须是 base64url 编码、解码后至少 32 字节的独立密钥。`cmd/api` 启动时严格校验,不允许复用百炼 API key,也不在日志中记录密钥。

token 使用带版本前缀的 HMAC-SHA256 派生,输入固定包含 owner、session/build 版本和 `Idempotency-Key`。输出是无填充 base64url 256-bit token;数据库仅保存 SHA-256 哈希。因此:

- 同一 build 与同一幂等键在 API 重启后仍能重建完全相同的 token 和 URL。
- 不同 build 或不同幂等键产生不同 token。
- 数据库泄露不会直接暴露可用公开 URL。
- 显式创建新链接必须生成新 UUID 幂等键。

## 4. 所有者管理与 HTTP API

已实现的接口:

- `POST /api/v1/sessions/{session_id}/builds/{version}/shares`
- `GET /api/v1/sessions/{session_id}/builds/{version}/shares`
- `DELETE /api/v1/sessions/{session_id}/builds/{version}/shares/{share_id}`
- `DELETE /api/v1/shares/{token}`
- `GET /api/v1/public/shares/{token}`
- `GET /api/v1/public/shares/{token}/export.md`

创建在事务内锁定并验证 build 所属。新建返回 201;同幂等键重试返回原分享与 200;同键却无法对应同一派生 token 时返回 409。同一 build 允许多个活动分享,本阶段不自动过期。

列表接口按创建时间倒序返回 `ShareRecord`,只包含 share ID、版本、创建时间和撤销时间,不包含 token 或 URL。工作台刷新后仍可列出和按 share ID 撤销旧链接,但不能再次复制原 URL。同一页面生命周期内刚创建的 URL 可重用,不使用 localStorage、Zustand 持久化或数据库明文 token。

创建、列表、按 ID 撤销与按 token 撤销都通过 build → session → owner 校验。不存在、越权、非法 token 和已撤销的公开读取统一返回 404,避免枚举差异。撤销是软删除,不物理移除审计行。

## 5. `PublicBuildView` 最小披露

公开 DTO 是独立结构,只允许:

- 中文友好的版本、父版本、生成时间和改单摘要。
- 预算、弹性、用途、目标游戏、分辨率、帧率、尺寸、噪音、品牌偏好、已有配件和优先品类。
- 八品类的 SKU、名称、数量、价格和理由。
- 总价、预算差、缺价、快照日期、12 条校验与三条免责。
- 校验的 rule ID、结果、严重性、缺失字段和说明。

明确排除 RequirementSpec `notes`、`observed`、owner/session/run/build 内部 ID、聊天历史、Agent/A2A 内部事件和错误堆栈。黑名单泄露测试防止后续重构意外扩大公开面。

## 6. 公开只读页

`/share/[token]` 是 Next.js Server Component,通过 `GO_API_BASE_URL` 在服务端读取 public API,不转发 Cookie。首屏 SSR 顺序固定为:需求摘要 → 八品类配置 → 价格摘要 → 12 条校验 → 三条免责。

页面标题为「装机配置单 vN · ¥总价」,metadata 包含用途、快照日期、canonical 与同一 PNG 地址。页面只提供复制链接、下载 Markdown 和下载分享图,不展示聊天、改单、会话入口或内部标识。无效或已撤销 token 统一进入 404,不展示 Go Problem detail。

工作台在 `PUBLIC_WEB_BASE_URL` 为 localhost、loopback 或私有网段时显示:

> 当前链接只在本机或可访问本机服务的网络内有效,尚未发布到公网。

## 7. Markdown 导出

所有者和公开导出都复用 `internal/presenter`,响应为 `text/markdown; charset=utf-8`。文件名统一为 `pc-build-v{version}-{snapshot_date}.md`,内容不包含 token、session、内部 ID 或网页控件。输出使用 UTF-8 无 BOM、LF 和文件末尾换行。

## 8. PNG 分享图

`/share/[token]/image` 使用 `ImageResponse` 生成 1200×630 PNG,同时作为 Open Graph 图和用户下载图,避免两套布局。图片展示产品名、版本、总价、用途、八类配件、总体校验和快照日期;超长型号单行截断,缺价与 pass/review/fail 同时使用图标和文字。

中文字体使用 OFL-1.1 授权包 `@pdfmergy-embedpdf/fonts-sc` 中的 Noto Sans SC,Node runtime 从本地依赖加载,不请求第三方字体或商品图片。数据不存在时返回 404,不生成空白配置图。

## 9. 缓存、隐私与发布边界

- 公开 JSON、Markdown、SSR 页和 PNG 全部使用 `Cache-Control: no-store`,保证撤销后立即失效。
- public API 不读取也不设置匿名 Cookie。
- 页面设置 `Referrer-Policy: no-referrer` 和 `X-Robots-Tag: noindex, nofollow, noarchive`。
- 页面不注入分析脚本、访问统计或第三方社交 SDK;打印样式隐藏按钮并保持正文可读。
- 正式公网发布前仍需同源 HTTPS、Secure Cookie、public GET 限流、日志脱敏和反向代理检查。

## 10. 测试与真实验收

自动测试覆盖:

- HMAC 稳定性、build/key 隔离、哈希存储、缺密钥启动失败。
- PostgreSQL 迁移、创建幂等、多分享、软撤销和所有权隔离。
- Public DTO 泄露黑名单,撤销前后 JSON/Markdown 状态。
- 工作台分享 Dialog/Drawer、幂等键复用、局域网提示、列表与撤销。
- SSR、统一 404、metadata、打印样式、PNG MIME 与 1200×630 尺寸。
- 375/768/1440 三种视口与 axe serious/critical 无障碍门禁。

2026-08-09 真实验收复用数据库中现有 v3,没有发送新消息、确认需求或调用百炼。验证结果:

1. 首次创建返回 201;API 重启后用同一幂等键重试返回 200,且 token/URL 完全相同。
2. 无 Cookie 公开 JSON、SSR、Markdown 和 PNG 全部 200;PNG 尺寸为 1200×630。
3. 公开响应不设置 Cookie,且不包含禁止字段。
4. 另一匿名身份撤销返回 404;所有者撤销返回 204。
5. 撤销后 JSON、SSR、Markdown 和 PNG 全部 404。
6. 验收期间模型调用数为 0。

分享与导出 已达到 DoD,下一阶段为 Live 验收 评测、真人验收与发布准备。
