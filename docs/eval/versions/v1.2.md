## 与旧题的边界

L1-010 只说已有显卡，L1-011 只说已有 CPU 和内存；两题都没有准确型号和预算口径。新执行器会正确追问，但旧期望仍为 pass，因此在原题对照中继续计失败。不能把它们从分母临时排除，也不能将新规则下的结果写回历史成绩。

L1-004 仍按 3000 元整机预算考核；本轮不补商品、不改价格或放宽预算。当前范围之外的真实市场可行性不由这份题库判定。

已有件旧契约题已在 [v1.3](v1.3.md) 用新 ID 显式迁移；本版本保留为历史对照，不重写题目或成绩。
