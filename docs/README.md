## 维护规则

- 文件按功能命名；ADR 编号表示决策身份，命令和数据中的历史编号保持兼容。
- 路线图只维护未完成事项、恢复条件与完成证据；不复制多份阶段清单。
- 实现文档说明现有行为和明确限制，计划中的能力不能写成已实现。
- 历史基线与运行日志保留日期和模型口径；不能把历史通过率当成当前版本成绩。
- Agent 字段以 `internal/schemas` 为准，HTTP 以 OpenAPI 为准，数据库以 `db/migrations` 为准；修改时同步维护对应文档。
