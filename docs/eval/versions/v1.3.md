## 判卷变化

新增 `expect.forbidden_clarify_fields`，仅用于 screening / clarify 题，支持 `budget_cny`、`budget_basis`、`owned_parts`、`resolution`、`use_case`。它与 `clarify_fields` 不得重复或冲突，未知字段会在离线检查时报错。

- S3 继续检查是否实际追问缺失项。
- S4 检查是否追问明确禁止的字段。问到了缺失项，同时重复确认已知信息，仍计失败。
- 普通复述“新增预算 6000 元已记录”允许；尾部再问“对吗？”或要求重新确认则算追问。
- “预算金额”和“预算口径”分别判定：询问“6000 元是新增费用还是整机总价”不等于重新索要金额。
- 历史题未声明新字段时不运行 S4，旧题口径不会被追溯加严。

S4 是中文规则近似，保留触发短句供复核，覆盖明确请求、尾问和请求列表。它不是开放域语义裁判；遇到误判先保存原话、补正反例并检查判卷，不为转绿删掉负向条件。正确复述与无关问题拼接、否定请求、跨段主题串接均有反例测试。
