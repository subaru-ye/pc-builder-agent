# P9 分享、导出与公开只读页 — 实现设计

> 状态:规划冻结,尚未实现。分享只暴露已保存的不可变 build 版本,不共享会话。

## 1. 目标与边界

P9 让配置单可以离开当前工作台被查看和保存,同时守住三个边界:

- 分享内容仍然遵守快照日期、校验三态和免责要求。
- 分享链接不泄露匿名身份、session、聊天和 Agent 内部数据。
- CLI、API、分享页不各自维护一套 diff/Markdown 业务规则。

本阶段支持 Markdown 下载、可撤销只读链接和 PNG 分享图。不支持协作编辑、评论、短链接服务、访问统计和社交平台 SDK。

## 2. 共享 presenter

当前 cmd/builds 的 decode、diff、export 在 main 包内。实施顺序必须先抽取确定性 presenter:

1. 定义 BuildView、BuildDiff 和 Markdown 渲染所需的内部领域投影。
2. 把 builds JSONB 解码、名称补全、金额差和免责文案移入共享包。
3. cmd/builds 改为参数解析 + store 调用 + presenter 输出。
4. cmd/api 使用同一 presenter 生成 JSON/Markdown。
5. 以现有 render_test 快照锁定格式,确保 CLI 兼容。

禁止:

- 前端重新计算总价或预算差。
- Next.js 根据零件字段重新判定兼容性。
- 分享页自行拼另一份免责文案。
- API 用浮点数重算价格。

## 3. 分享数据模型

build_shares 字段:

| 列 | 类型 | 说明 |
|---|---|---|
| id | bigint identity | 内部主键,不出 API |
| build_id | bigint | FK builds(id),分享固定版本 |
| token_hash | bytea | SHA-256 原始 token,唯一 |
| created_at | timestamptz | 创建时间 |
| revoked_at | timestamptz nullable | 撤销标记 |

token 规则:

- crypto/rand 生成至少 256 bit 随机数。
- base64url 无填充编码,只包含 URL 安全字符。
- 原始 token 只在创建响应和 URL 中出现;日志只记录 share id/token 前 6 位不可逆指纹或完全不记。
- 查询时对 URL token 哈希后命中 token_hash。
- 不提供顺序 ID、短码或可枚举 slug。

所有权通过 build.session_id → web_sessions.owner_id 校验。因为旧 dev UI build 不一定有 web_sessions,它们只能继续用 CLI,不能直接创建 Web 分享。

## 4. 创建与撤销

### 4.1 创建

POST build/{version}/shares:

1. 校验匿名 owner 和 build 属于 session。
2. 校验 Idempotency-Key。
3. 生成 token/hash 并插入 build_shares。
4. 用 PUBLIC_WEB_BASE_URL 构造 /share/{token}。
5. 返回一次原始 token、URL 和 created_at。

同一 build 可以有多个分享,但相同幂等键必须返回同一条。UI 默认复用当前未撤销分享,不为每次点击制造新 token。

### 4.2 撤销

DELETE /api/v1/shares/{token}:

- 必须有 owner cookie 且通过 build 反查所有权。
- 更新 revoked_at,不物理删除审计行。
- 重复撤销返回 204。
- 他人 token 与不存在统一 404。
- 撤销后 public GET、页面和图片均返回统一失效状态。

阶段 1 不设置自动过期。若未来公开部署需要有效期,新增 expires_at 并版本化契约,不得改变现有 token 的含义。

## 5. PublicBuildView 最小披露

公开内容允许:

- vN 展示编号、生成时间和改单意图的用户友好名称。
- 结构化需求摘要,但 notes 在公开 DTO 中默认排除,防止用户写入私人信息。
- 八品类零件、SKU、品牌型号、数量、理由和价格。
- 总价、预算、差额、缺价和快照日期。
- ValidationReport 的结果、detail 和 missing fields。
- 固定免责文本和分享创建时间。

公开内容禁止:

- owner_id、session_id、run_id、内部 build id、requirement id。
- 用户/assistant 对话历史。
- 原始 RequirementSpec notes。
- Agent tool args、思维、A2A context/task。
- 数据库连接、模型配置、错误堆栈。

公开 DTO 虽可复用 BuildView 展示字段,实现时必须有独立映射函数和泄露字段测试,不能直接 JSON encode store row。

## 6. 只读分享页

路由 /share/[token] 使用 Server Component:

- 服务端调用 GET public share,首屏直接渲染完整配置。
- 页面不读取匿名 cookie 也能访问。
- 标题为「装机配置单 vN · ¥总价」,描述包含用途与快照日期。
- 主体顺序:需求摘要 → 配置列表 → 价格摘要 → 校验 → 免责。
- 无聊天、改单、会话跳转或数据库内部链接。
- CTA 仅允许「下载 Markdown」「下载分享图」「复制链接」。
- token 失效统一 404 页面;不展示 Go Problem detail。

当 PUBLIC_WEB_BASE_URL 的 hostname 是 localhost、127.0.0.1 或局域网地址时,创建分享后的 UI 显示:

> 当前链接只在本机或可访问本机服务的网络内有效,尚未发布到公网。

不得使用「公开链接」文案误导用户认为互联网可访问。

## 7. Markdown 导出

- URL 保留现有版本语义,响应 Content-Type 为 text/markdown; charset=utf-8。
- Content-Disposition 文件名使用 pc-build-v{version}-{snapshot_date}.md,只含安全 ASCII。
- 内容与 cmd/builds export 使用同一 presenter。
- 必含需求摘要、全部大件、价格/缺价、总价、快照日期、校验摘要和三条免责。
- Markdown 不含分享 token、session id、内部 ID 或网页专属控件。
- 输出保持 UTF-8 无 BOM、LF、文件末尾换行。

## 8. PNG 分享图

Next.js 使用 app/share/[token]/opengraph-image.tsx 或等价 ImageResponse 渲染。它只负责公开 DTO 的视觉排版:

- 尺寸 1200×630,同时作为 OG 图和下载图基础。
- 深色 Linear 派生 token,不复制 Linear 标识。
- 展示产品名、vN、总价、用途、8 类配置精简名称、总体校验和快照日期。
- 免责缩写为「快照参考价;下单前复核官方规格」,完整免责仍在页面。
- 超长型号单行截断,不得缩到不可读。
- pass/review/fail 同时有文字和图标。
- 不远程加载商品图片,避免版权、超时和不可复现。

下载按钮请求同一图像路由并以 blob 下载。ImageResponse 获取 public DTO 失败时返回通用错误图或 HTTP 404,不得渲染空配置。

## 9. 缓存与隐私

- Public API 默认 Cache-Control: public, max-age=60, stale-while-revalidate=300;撤销后允许最多 60 秒 CDN 陈旧窗口的风险必须在正式公网部署前复核。
- 本地可使用 no-store 简化撤销验收。
- 分享页面不注入分析脚本,阶段 1 不记录访问者 IP/UA。
- token 不进入第三方请求 Referer;页面设置 Referrer-Policy: no-referrer。
- 页面资源不包含需要把完整分享 URL发送给第三方的远程字体或图片。
- 分享创建前提示「任何拿到链接的人都可查看这份配置」。

## 10. 公网发布准备清单

本阶段不要求实际发布,但文档与配置必须明确:

- 前端/API 使用同源 HTTPS 或受控反向代理。
- PUBLIC_WEB_BASE_URL 是最终 HTTPS 地址。
- 匿名 cookie 开启 Secure。
- 代理关闭 SSE 缓冲并允许超过 10 分钟连接。
- 分享页/图片可由外部访问,私有会话 API 不允许无 cookie 访问。
- 日志脱敏 token、cookie、prompt 中可能的个人信息。
- 为公共 GET 增加速率限制后才能面向互联网开放。
- 多实例前必须替换阶段 1 的单进程后台 run 模型。

## 11. 测试与 DoD

- presenter 单测证明 CLI、JSON 和 Markdown 金额/版本语义一致。
- 创建 token 随机性、哈希存储、幂等和多分享测试。
- owner A 不能创建/撤销 owner B 的分享。
- public DTO 泄露字段黑名单测试。
- 撤销前 200、撤销后 404、随机 token 404。
- 分享页 SSR、404、打印样式、Markdown 下载和 PNG 尺寸测试。
- localhost 提示存在;配置公网 URL 后提示消失。
- 分享图在超长中文/英文型号、缺价和三种校验状态下可读。
- README 演示用例能从 v3 创建链接、下载 Markdown/PNG、撤销并验证失效。
