## 标注口径

- **快走候选（label=是）**：金标效果为唯一 `set budget_cny=<值>`，无执行请求/追问/歧义信号，无 forbidden 操作，且**值来自本轮原话**（提案接受协议轮不算——原话无数值，确定性快走拿不到候选值）。
- **回退（label=否）**：其余一切轮次，包括复合消息、封顶/弹性/口径等预算语义扩展、restore/conflict 操作、执行请求、提问、引用报价、拒绝与撤回。
- 规则阶段（rule_stage）是 C1–C9 规则链对该轮的判定，词表见 `internal/planningeval/fastlane.go`；多值判定发生在哨兵区间（500–200000）过滤之后。

### Set B 设计意图

- 正例 8 轮：典型"改成"、千分位、中文数字、采纳句式（那就/就…吧）、已确立预算的上调/下调。
- 负例 17 轮：询问（够吗/怎么样/合适吗/随便问问）、引用报价（看到报价/别人家/之前配置单）、拒绝（不行/不定）、撤回（先不算/不限定）、复合（机箱/硬盘）、多值、无金额。
- `sb-rep-ask-002`（预算7500能配出什么效果）、`sb-rep-ask-003`（预算7500只是随便问问）、`sb-rep-ref-001`（之前那个7500的配置单还能用吗）是为纯规则词表缺口设计的对抗样本——影子运行确认纯规则误快其中 2 轮，R+J 全部正确回退。
- `sb-rep-det-004`（预算定为八千五）暴露复用解析器的真实缺口：`chineseBudgetNumber` 把"八千五"解析为 8005 而非 8500（"千五"口语结构未覆盖）——该轮 R/R+J 都会以错值 8005 快走，是本实验记录的**唯一关键字段错写**；语料中无此类表达，但生产化前必须处理。
