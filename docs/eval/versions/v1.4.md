## 预算证明与用户说明

原有独立品类最低价证明保留。新增平台证明用于**无已有件、无基版本、非改单的 general 整机**：枚举完整目录的 CPU、主板与内存，仅排除已知的插槽、芯片组、内存代际冲突，无核显 CPU 计入最低独显价，其余必需品类取最低价。忽略其他限制会扩大可行集合，因此所得金额是乐观下限，不是通过全部规则的装机方案。

未知价格、无法解析的规格或超过 50 万组的平台枚举均放弃该证明；未知规格字段按可能兼容处理，未知核显状态按可能有核显处理，避免因信息不足错误拒绝。已有件和改单继续使用原有逻辑。下限必须严格大于预算弹性上限，等于上限时不拒绝。

新平台说明由程序生成，明确当前目录与快照范围；告知调整预算后重新校验、提供已有配件完整型号与预算口径、补充可核验商品资料等选择。不会把下限说成必能装成的报价，不自动提高预算，也不保存超预算配置版本。
