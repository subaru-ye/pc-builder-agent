# P12B 实施记录

> 日期：2026-08-27。状态：离线实现与迁移通过，等待真实 canary；P12B 未完成。

## 已完成

- 新增 SerpApi Free / Baidu Shopping 适配器；只请求官方 API，不访问商城页面，不调用模型。
- 每批先调用免费的 Account API，强制 Free 套餐、账户剩余额度和项目每月 240 次硬限制。
- 固定 12 SKU canary、96 SKU 待激活核心池和版本化身份规则。
- 搜索结果严格解析单一 CNY 价格、HTTPS 链接、品牌、型号和冲突 token；条件价、错误变体和无商家结果拒绝。
- `collector_id=serpapi_baidu` 与底层 `source_id` 分离；`listing/search_listing/unknown` 明确表示“有报价但未确认库存”。
- 同 SKU 至少两个独立商家/目标主机才可参与确定性中位数实际报价选择。
- 新增 migration 10、API/Web/分享页/Markdown 报价依据提示和每日 7 SKU 调度代码。
- 激活门禁为 fail-closed：映射和 registry 任一未激活，daily 拒绝；安装脚本不安装 PriceDaily，CatchUp 不消费额度。

## 本轮验证

- Go 全量测试、vet、build 通过；PostgreSQL/Redis 指定集成测试通过。
- Windows 原生 race 仍受 ThreadSanitizer 高地址内存保留错误阻塞；官方 `golang:1.26.5` Linux 容器执行 `go test -race -count=1 ./...` 全部通过。
- Python 155 项测试通过，其中 fake SerpApi 覆盖 Free 套餐、预算、429、精确匹配、双商家、96 条固化映射和 12 次 canary。
- Web OpenAPI 类型生成、lint、typecheck 和 unit 通过。
- 本轮模型调用数为 0。
