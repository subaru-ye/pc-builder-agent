## 1. 范围与政策门禁

- 真实来源仅为 AMD 官方 CPU 具体型号页，固定映射当前 13 个 AMD CPU SKU，不搜索全站、不自动发现新品。
- AMD `robots.txt` 在验收时未禁止这些产品路径。采集器保存并核对 robots 原文摘要，以及去除脚本、样式和动态属性后的条款可见文本摘要。
- 条款、robots、资源主机、页面身份或结构变化均会隔离来源，不绕过登录、验证码、401/403/429 或跨主机重定向。
- NVIDIA 自动网页采集因其服务条款明确禁止 robot、scraper、crawler 和自动数据提取而排除。
- 全程 `model_used=false`；没有调用百炼、MiMo 或其他模型。

政策参考：[AMD robots](https://www.amd.com/robots.txt) · [AMD 条款](https://www.amd.com/en/legal/terms-and-conditions.html) · [AMD 产品页示例](https://www.amd.com/en/products/processors/desktops/ryzen/ai-400-series/amd-ryzen-ai-7-450g.html) · [NVIDIA 服务条款](https://www.nvidia.com/en-eu/about-nvidia/terms-of-service/)
